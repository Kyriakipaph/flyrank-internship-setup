# TierUp

A focus timer that grows a tiered cake while you work. The longer you stay
focused, the taller and more elaborate the cake gets. Give up early and it
gets smashed. Completed cakes are saved so you can look back at your focus
history over time.

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- ESLint

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Routes

- `/` — start a focus session (timer and cake)
- `/kitchen` — gallery of completed cakes
- `/tasks` — plan and track tasks
- `/health` — deployment health check
